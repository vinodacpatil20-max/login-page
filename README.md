# Login Page

## 📌 Project Description

This project is a simple and user-friendly Login Page designed to provide users with a clean and attractive interface for logging into a website.

## 🎯 Objectives

* Create a simple and attractive login interface.
* Provide input fields for username/email and password.
* Make the design responsive and user-friendly.
* Improve understanding of frontend web development.

## ✨ Features

* User-friendly interface.
* Username and password fields.
* Login button.
* Clean and attractive design.
* Responsive layout.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file.
4. Run it using Live Server or your browser.
